方案 A 手法总结
· Stroke：1.7px（与 tab bar 完全一致）
· Cap/Join：round / round
· 基础尺寸：24×24 viewBox
· 实际渲染：tab 24px / 页面标题 22px / 场景卡 26px / 状态 18px / shortcut 22px / arrow 16px
· 颜色：默认 ink-1 描边；destructive = primary 书签红；success = moss 墨绿；accent = gold 古铜金
· fill：全部 none（默认），激活态 tab item 用 currentColor 改色，不做填充状态
· emoji 处理：全部换成 line-icon，分类 chip 去 icon（只留文字）
