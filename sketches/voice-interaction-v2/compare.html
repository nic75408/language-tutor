B 胜的核心理由：赤拔抱怨的根问题是「都重叠了」——B 用「零新增层」的物理策略从源头消除了这个类问题。
A 落选：为了消除重叠付出了太大代价（遮挡消息历史 + 与本站无 modal 的 HIG 决定冲突）。
C 落选：需要两个不同容器（推起层 + composer）承载两个态，实现和动画都更复杂，视觉收益却不明显。
待发送态（三案共守）：录音结束后 composer 还原为普通输入框，内左侧多一个红色脉冲 dot + 识别出的文字（primary-soft 底 + primary 边框 1.5px），发送按钮变红色并呼吸；用户点发送按钮 = 发送，点输入框任意位置 = 进入编辑（dot 消失，边框还原为 rule 灰）。不再有独立徽章。
P2 状态栏溢出：所有方案顶部保留 44px safe-area-inset-top；conversation 页面的 layout 修正为不覆盖 `.page-outlet` 的 padding-top。
