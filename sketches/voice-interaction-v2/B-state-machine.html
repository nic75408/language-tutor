关键不变量：整个流程只有一个 composer 容器；任何时刻它只处于四态之一；四态互斥、由单一 CSS class 切换（idle / rec / pending / sending）。永远不会出现两个语音相关的视觉元素同时可见。

取消录音：录音态时，用户可将手指从麦克风按钮"滑走"离开按钮范围（touchmove），或点击 composer 上方浮现的"← 滑走取消"提示。取消 = 直接回 idle，无 pending 态。
点输入框编辑：pending 态时用户点输入框任意位置 → 移除 pending class，dot 消失，边框还原为 rule，用户可编辑文字。
iOS HIG 合规：麦克风按钮和停止按钮位置一致（同一 x 坐标），只切颜色和图标——用户"按住 / 松开"的手感一致。热区 40×40（视觉）+ 44px 内边距 padding 保证 44 tap target。
safe-area：composer padding-bottom 已含 `env(safe-area-inset-bottom)`；顶部消息区继承 page-outlet 的 safe-top。
