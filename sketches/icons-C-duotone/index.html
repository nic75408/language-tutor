方案 C 手法总结
· 手法：SF Symbols 的 "Duotone" 变体——stroke 描边 + 同色 18-22% 透明填充
· 激活态：填充可增强到 fill-opacity: 0.35 或直接反转背景
· 优点：状态语义最清晰（未激活/激活对比强）、视觉层级最丰富
· 缺点：18% fill 是"多出来的一层色块"，与 Newsprint"文字为主纸感"美学有张力；同一屏 8+ 场景 icon 全带 fill 会形成"色块阵列"分散注意力
· SVG 结构复杂度：每个 icon 从 1 个 <path> 变 2 个（fill + stroke），代码/DOM 体积翻倍
· 命中：需要强激活反馈的产品（Notion 侧栏、Linear tag）——语言学习工具是否需要这种强度？
