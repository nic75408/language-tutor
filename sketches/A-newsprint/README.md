# 变体 A：Newsprint 编辑室（**胜出 · 定稿**）

## Design stance
「跟一位有教养的老师读一本英文书」的意象。米白纸感底 + 衬线大标题 + 无衬线正文 + 书签红作为唯一强调色。像 The Atlantic 的读书笔记本，或 Notion 官网的暖极简 + 报刊排版。

## Key choices
- **色**：米白 `#F7F3EC` 纸感底 / 深墨黑 `#1C1B18` 正文 / 书签红 `#B23A28` 唯一强调 / 已掌握墨绿 · 学习中土黄 · 语义色克制。
- **字**：英文标题 Source Serif 4（细笔画衬线，专业读物感）、正文 Inter、元数据 JetBrains Mono、中文 Inter/PingFang 自动 fallback。
- **中英混排**：英文用衬线做主视觉，中文注解用无衬线小字 + 左侧书签红竖线导——**一眼看到英文，需要时看中文**。
- **交互**：气泡对话老师裸文本、用户黑色胶囊；进度用金属细笔画圆环；任务清单方形 checkbox。

## Trade-offs
- **强在**：识别度高、成人质感、中英混排最舒适、可扩展到 10+ 页面不会累。目标用户（40 岁成人中文母语学英语）拟合度最高。
- **弱在**：书签红作为唯一强调可能不够"欢快"，需要靠"12 天连续"这类数字激发情绪。

## Best for
成年中文母语者的长期英语学习工具——每日 15-30 分钟碎片时间使用，视觉上不"消耗心力"、可以每天面对。

## 自评得分：48 / 50（三案第一）
- Tab 清晰 4 · 输入布局 5 · 成人感 5 · 混排 5 · token 落地 5
- 温暖不幼稚 5 · 文化质感 4 · 用户拟合 5 · 扩展性 5 · 实现难度 5
