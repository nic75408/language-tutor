# 变体 C：Studio 现代工具（落选）

## Design stance
「一台精密仪器」的意象。近黑 + 纸白 + 靛蓝工具色，Inter + Noto Sans SC，圆角克制，全无衬线。像 Linear、Cal.com、Vercel、iOS Reminders 的移动端。

## Key choices
- **色**：纸白 `#FBFBFA` 底、近黑 `#17171A` 正文、靛蓝 `#4759F5` 工具色。
- **字**：Inter（英文）+ Noto Sans SC（中文），全无衬线。
- **首页**：把中文当视觉焦点（大字标题），对中文用户语言亲切度最高。
- **组件**：卡片带圆角+细边、checkbox 打勾靛蓝、任务用行卡片、词条也是卡片。

## Trade-offs
- **强在**：Tab 图标最好懂、功能感极强、"待办事项"抽象最直接。
- **弱在**：**温度弱**——像 Anki、Notion 数据库，不像"有一位老师在教你"。产品定位"AI 私教陪你对话"的**人味**被工具化消解。对话页靛蓝色强调用得过多（每个气泡都有蓝字，语义分层失效）。

## Best for
- 未来项目的**设置页 / 数据密集的仪表盘页 / Debug/开发者视图**
- iPad/桌面端如果做的话，C 案的模式更合适（长屏、多列、密度更高）

## 自评得分：44 / 50（三案第三）
- Tab 清晰 5 · 输入布局 4 · 成人感 5 · 混排 5 · token 落地 5
- 温暖不幼稚 3 · 文化质感 3 · 用户拟合 4 · 扩展性 5 · 实现难度 5

## 从此案吸收进 A 案定稿
- Checkbox 打勾态用 accent 色填充（比 A 版纯黑更醒目、更"完成"）
- 搜索栏形态（词库/语法页顶部搜索输入的 pattern）
- 卡片式词条布局作为词库"卡片视图"（与 A 案的"报刊列表视图"并存，用户可切换）
- 图标 stroke 略粗到 1.7px（比原 A 案 1.6px 更清晰，尤其在 Retina 移动屏上）
